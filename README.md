# 7nPay - 支付安全更便捷

7nPay是一个专业的虚拟商品交易平台，为用户提供一站式支付解决方案。

## 主要特点

- **超简入驻流程，实时结算**：低门槛快速入驻，资金自动结算
- **支持微信实时推送**：订单、售卡、投诉等消息实时通知
- **AI智能防护**：识别拦截DDOS、CC攻击，全网最长运营，无差评

## 支持的支付方式

- 微信支付
- 支付宝支付
- QQ钱包支付
- 银联支付

## 技术栈

- HTML5
- CSS3
- JavaScript
- 响应式设计
